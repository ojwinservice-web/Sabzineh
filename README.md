# سبزینه — وب‌سایت فروشگاهی (HTML / CSS / JS خالص)

این پروژه از طراحی Google Stitch («Atelier of Persian Flavors») استخراج و به
یک وب‌سایت کامل، فارسی و راست‌به‌چپ (RTL) برای برند **سبزینه** تبدیل شده است.
هیچ Build Step، npm یا Framework‌ای در آن استفاده نشده — فقط HTML، CSS و
Vanilla JavaScript.

## ساختار پروژه

```
index.html          صفحه اصلی (هیرو، دسته‌بندی‌ها، محصولات پرفروش، شرایط عمده)
products.html        کاتالوگ کامل محصولات با فیلتر، جستجو و مرتب‌سازی
about.html            درباره ما (داستان برند، آمار، ارزش‌ها، مسیر رشد)
contact.html          تماس با ما (فرم تماس، تلگرام/واتس‌اپ)
assets/
  css/style.css        استایل‌های مشترک، افکت شیشه‌ای (Glass)، انیمیشن‌ها
  js/config.js         اطلاعات فروشگاه (تلگرام، تلفن و ...)
  js/tailwind-config.js  تنظیمات رنگ/فونت Tailwind (از Design System استخراج‌شده)
  js/products-data.js  دیتای محصولات (قابل ویرایش)
  js/products-render.js  رندر کارت محصولات + فیلتر/جستجو/مرتب‌سازی
  js/cart.js            سبد خرید (localStorage) + ثبت سفارش در تلگرام
  js/main.js             منوی موبایل، اسکرول‌ریویل، هدر چسبان، Toast
  images/                 تصاویر واقعی محصولات (استخراج‌شده از پروژه Stitch)
```

## انتشار روی GitHub Pages (Drag & Drop)

1. یک ریپازیتوری جدید در GitHub بسازید (یا از ریپازیتوری موجود استفاده کنید).
2. تمام فایل‌ها و پوشه‌ی `assets/` را با Drag & Drop در صفحه‌ی ریپازیتوری آپلود کنید
   (یا در تنظیمات ریپازیتوری گزینه‌ی «uploading an existing file» را انتخاب کنید).
3. به Settings → Pages بروید، شاخه (Branch) را انتخاب کرده و Save بزنید.
4. سایت شما در آدرس `https://<username>.github.io/<repo>/` در دسترس خواهد بود.

هیچ مرحله‌ی Build، Compile یا نصب Dependency لازم نیست — فایل‌ها همان‌طور که
هستند روی GitHub Pages اجرا می‌شوند.

## تنظیمات فروشگاه (از قبل وارد شده)

فایل `assets/js/config.js` هم‌اکنون با اطلاعات زیر تنظیم شده است:

```js
window.SABZINEH_CONFIG = {
  storeName: "سبزینه",
  telegramUsername: "Sabzinehco_bot", // t.me/Sabzinehco_bot
  phone: "09967931159",
  mobile: "09967931159",
  whatsapp: "989967931159"
};
```

در صورت نیاز به تغییر شماره تماس، آیدی تلگرام یا اینستاگرام، فقط همین یک
فایل را ویرایش کنید — تمام لینک‌ها در همه‌ی صفحات به‌طور خودکار به‌روزرسانی
می‌شوند (نیازی به ویرایش HTML نیست).

## ویرایش محصولات

محصولات در `assets/js/products-data.js` به شکل یک آرایه‌ی ساده تعریف شده‌اند.
برای افزودن/ویرایش محصول، یک آبجکت جدید با همان ساختار اضافه کنید و تصویر
مربوطه را در پوشه‌ی `assets/images/` قرار دهید.

## قابلیت‌ها

- ناوبری کامل بین ۴ صفحه با هدر چسبان (Sticky) و منوی موبایل
- افکت شیشه‌ای (Glassmorphism) در هیرو، دکمه‌های شناور و بنر CTA
- انیمیشن‌های Scroll Reveal، Hover و Float با CSS و IntersectionObserver
- طراحی کاملاً واکنش‌گرا (Responsive) برای موبایل، تبلت و دسکتاپ
- کاتالوگ محصولات با فیلتر دسته‌بندی، جستجوی زنده و مرتب‌سازی قیمت
- سبد خرید مبتنی بر `localStorage` با شمارنده، افزایش/کاهش تعداد و حذف
- ثبت سفارش مستقیم در تلگرام از طریق ربات @Sabzinehco_bot (هم از سبد خرید و هم از فرم تماس)

## وابستگی‌های خارجی (CDN — بدون نیاز به نصب)

این پروژه برای رعایت «بدون Build Step» از CDN‌های زیر استفاده می‌کند که در
زمان اجرا (Runtime) در مرورگر بارگذاری می‌شوند و نیازی به نصب یا Build ندارند:

- Tailwind CSS (Play CDN) — `cdn.tailwindcss.com`
- فونت Vazirmatn — `cdn.jsdelivr.net`
- فونت‌های Google (Plus Jakarta Sans / Be Vietnam Pro) و Material Symbols

اگر می‌خواهید سایت کاملاً بدون هیچ درخواست خارجی کار کند، می‌توانید این
فایل‌ها را دانلود کرده و به‌صورت لوکال در `assets/` قرار دهید و مسیرها را در
فایل‌های HTML اصلاح کنید.
